    La web municipal usa el mismo color para reservas y bloqueos, así que un cierre de pista también cuenta como reservado. Las reservas son aproximadas: cada bloque de franjas seguidas cuenta como una, aunque sean dos reservas consecutivas. La ocupación se calcula de 08:00 a 24:00 sobre las franjas con dato. Todas las pistas de pádel menos Pádel 3 cierran de 22:00 a 24:00, y esas horas no cuentan.
